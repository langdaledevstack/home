# Mark Heard — Professional Portfolio

Static GitHub Pages portfolio for:

**Enterprise Architect | Integration | APIs | Data Architecture | Solution Design | Technical Delivery**

## Structure

- `index.html` — main portfolio
- `case-studies/` — selected case studies
- `assets/style.css` — site styling
- `cv/Mark-Heard-CV.pdf` — add your final CV here

## Before publishing

Replace these placeholders in `index.html`:

- `YOUR.EMAIL@example.com`
- `YOUR-LINKEDIN`
- `YOUR-GITHUB`

Add the final CV at:

`cv/Mark-Heard-CV.pdf`

The site is intentionally static HTML/CSS so it can be published directly through GitHub Pages without a build dependency.
